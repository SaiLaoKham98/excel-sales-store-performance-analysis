
# DAX Measures — Sales & Store Performance Analysis

This document explains the core DAX measures used in the Excel Power Pivot Data Model.

## 1. Total Sales

```dax
Total Sales :=
SUMX(
    SalesRaw,
    SalesRaw[Units Sold] * SalesRaw[UnitPrice]
)
```

Calculates total transaction revenue by multiplying units sold by unit price for each sales record.

## 2. Total Margin Amount

```dax
Total Margin Amount :=
SUM(SalesRaw[Margin Dollar])
```

Calculates the total margin amount across the selected transactions.

## 3. Total Margin %

```dax
Total Margin % :=
DIVIDE(
    [Total Margin Amount],
    [Total Sales]
)
```

Measures the proportion of sales retained as margin.

## 4. Previous-Year Sales

```dax
Sales Previous Year :=
CALCULATE(
    [Total Sales],
    SAMEPERIODLASTYEAR(Dim_Date[Date])
)
```

Retrieves sales for the corresponding period in the previous year.

## 5. Year-over-Year Sales Growth

```dax
Sales YoY Growth % :=
DIVIDE(
    [Total Sales] - [Sales Previous Year],
    [Sales Previous Year]
)
```

Measures sales growth against the corresponding previous-year period.

**Important:** Interpret this measure in a valid date context, such as 2019 compared with 2018.

## 6. Active Sales Days

```dax
Active Sales Days :=
DISTINCTCOUNT(SalesRaw[DateID])
```

Counts the distinct dates on which sales transactions were recorded.

## 7. Average Daily Sales

```dax
Sales Per Day :=
DIVIDE(
    [Total Sales],
    [Active Sales Days]
)
```

Calculates revenue per active sales day.

## 8. Promotional Sales

```dax
Promo Sales :=
CALCULATE(
    [Total Sales],
    SalesRaw[Promo] <> ""
)
```

Calculates revenue associated with transactions carrying a nonempty promotion code.

## 9. Promotional Sales Contribution

```dax
Promo Sales % of Total Sales :=
DIVIDE(
    [Promo Sales],
    [Total Sales]
)
```

Calculates the percentage of total revenue generated by promotional transactions.

## 10. Product Sales Contribution

```dax
Product Sales % of Total :=
DIVIDE(
    [Total Sales],
    CALCULATE(
        [Total Sales],
        ALL(Dim_Products)
    )
)
```

Measures product revenue contribution relative to total sales after removing product-dimension filters.

## 11. Manager Sales Contribution

```dax
Manager Sales % of Total :=
DIVIDE(
    [Total Sales],
    CALCULATE(
        [Total Sales],
        ALL(ManagerListTable)
    )
)
```

Calculates each manager's sales contribution while removing manager-dimension filters from the denominator.

---

## Technical Concepts Demonstrated

- Row-context iteration using `SUMX`
- Filter-context modification using `CALCULATE`
- Time intelligence using `SAMEPERIODLASTYEAR`
- Safe division using `DIVIDE`
- Distinct counting
- Contribution-to-total calculations using `ALL`

These measures support the project's interactive KPI cards, PivotTables, charts, and business performance analysis.
